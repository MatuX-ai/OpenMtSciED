# 01 - 项目概述

## 1. 项目名称

**OpenMTSciEd** — Open Science & Technology Education（开放 STEM 教育资源平台）

## 2. 项目背景

STEM（科学、技术、工程、数学）教育资源分散在 Khan Academy、OpenStax、Coursera、OpenSciEd 等多个平台，缺乏统一检索、关联与个性化学习路径能力。OpenMTSciEd 旨在整合优质开放教育资源，通过知识图谱与开放 API，为教育者、开发者和学习者提供一站式 STEM 学习与教学支持。

## 3. 项目愿景

> 让 STEM 教育资源触手可及 — 开放、智能、可集成。

## 4. 项目目标

| 目标 | 描述 |
|------|------|
| 资源整合 | 聚合多平台课程、教材、题库、硬件项目等 STEM 资源 |
| 智能学习 | 基于 Neo4j 知识图谱生成学习路径与个性化推荐 |
| 开放集成 | 提供 RESTful API，供第三方应用与 iMato 等平台集成 |
| 多端覆盖 | 网站（营销/轻量）、桌面端（完整学习）、管理后台（运营） |
| 开源共建 | MIT 许可证，社区驱动内容与代码贡献 |

## 5. 核心价值主张

- **对教师**：获取结构化教程、课件与硬件项目方案，辅助课程设计
- **对学生/自学者**：获得个性化学习路径、题库练习与硬件实践项目
- **对开发者**：通过开放 API 集成 STEM 资源到自己的产品
- **对平台运营者**：通过爬虫与后台管理持续扩充资源库

## 6. 项目范围

### 6.1 范围内（In Scope）

- STEM 教程、课件、课程、教材章节的浏览与管理
- 知识图谱驱动的学习路径与资源推荐
- 硬件项目（Arduino、机器人等）展示与管理
- 题库与练习系统
- 用户注册、登录、个人资料与学习记录
- 管理员后台：用户、爬虫、教育平台、资源关联等
- 桌面客户端：离线友好的学习与资源管理
- 静态营销网站与开发者门户

### 6.2 范围外（Out of Scope，当前版本）

- 完整的在线视频托管与流媒体服务
- 实时协作与在线课堂
- 商业化计费与支付系统
- 原生移动端 App（Phase 3 计划）
- 完整的 AI 内容生成流水线（Phase 3 计划）

- `PROGRESSES_TO`: 28,380 条（先修/进阶关系）
- `CONTAINS`: 4,612 条
- `BELONGS_TO`: 539 条

## 8. 成功标准

1. 后端 API 稳定可用，核心端点响应时间可接受（见非功能需求）
2. 用户可通过桌面端或网站完成注册、登录、浏览资源、生成学习路径
3. 管理员可通过后台管理用户、触发爬虫、维护资源关联
4. 第三方开发者可依据 API 文档在 30 分钟内完成基础集成
5. 文档体系完整，新成员可依据 `docs/` 快速理解项目
